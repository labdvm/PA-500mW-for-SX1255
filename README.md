# PA-500mW-for-SX1255
500mW PA for SX1255 with TQP7M9106

# With this PA the direct signal from SX1255 should be amplified around 400~500 mW clean Tetra signal.
# Board thickness is 0.8mm
- The L2,L3,L4 must be "wirewound" for better Q factor.
- The capacitors from the 100pF and below must be with 1% tolerance or better.
